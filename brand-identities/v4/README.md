# Reservo v4 · PÍLDORA

**Idea:** una agenda de clases hecha de cápsulas blandas, fotos que desbordan y una energía cercana de barrio.

- **Paleta:** usa únicamente los colores de Kinaf. El celeste `#5AB8F0` selecciona y organiza; el verde `#8CC463` acompaña; el verde brillante `#6EF04A` activa; el navy `#001A4D` concentra navegación, contraste y estados; el azul `#3E88F0` codifica información. El blanco y las tintas de baja opacidad sostienen el aire.
- **Tipografía:** Nunito Sans. Pesos 900 para títulos redondos y expresivos; 600–800 para interfaz; cifras tabulares para horarios, cupos y montos.
- **Radios y elevación:** tarjetas de 28–42 px, controles y navegación de 999 px, avatares circulares. Sombras blandas con caída visible, nunca halos.
- **Voz:** rioplatense, clara y amable; voseo marcado, frases cortas y una sonrisa sin infantilizar.
- **Racional:** la suavidad baja la fricción de reglas como cupos, planes y pagos; las fotografías recortadas mantienen el movimiento y el navy evita que lo lúdico pierda confianza.
- **Diferencia:** no es un tratamiento light genérico porque las cápsulas, el desborde fotográfico y la composición superpuesta dominan cada pantalla. Tampoco es un tratamiento navy genérico: el navy aparece como ancla y no como fondo total; verde y celeste llevan el ritmo visual.

## Render

Desde la raíz del proyecto:

```bash
node render.mjs v4
```
