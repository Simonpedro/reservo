# Reservo · AIRE

**Idea:** una agenda de movimiento respirable y cercana, donde reservar se siente tan simple como hablar con la recepción de Kinaf.

- **Paleta:** blanco como campo principal; navy `#001A4D` para texto, navegación y autoridad; verde `#8CC463` para acciones; celeste `#5AB8F0` y azul `#3E88F0` en tarjetas y estados; verde brillante `#6EF04A` sólo como chispa breve. Todos los fondos suaves son transparencias de estos colores.
- **Tipografía:** Bricolage Grotesque variable. Peso 800 para títulos compactos, 650–700 para controles y 500–600 para apoyo.
- **Forma:** radios de 20–32 px, pills para estados y días, elevación suave con caída navy. Los atletas recortados rompen los bordes de las tarjetas.
- **Voz:** rioplatense, cálida y concreta; habla como quien ya conoce a la persona: “Listo, Sofi. Te guardamos tu lugar”.
- **Racional:** AIRE conserva el ritmo del referente —saludo, semana horizontal, tarjetas grandes, fotos en movimiento y navegación flotante— y lo traduce íntegramente a Kinaf.
- **Diferencia:** no es un tema claro genérico ni un dashboard navy. El blanco organiza el ritmo, cada color ocupa superficies completas y la fotografía desborda; el admin mantiene la misma identidad con una densidad más operativa.

## Archivos

Abrí los HTML directamente o ejecutá desde la raíz:

```bash
node render.mjs v1
```

Las imágenes recortadas provienen de PikWizard y se sirven por HTTPS; la tipografía se carga desde Google Fonts.
